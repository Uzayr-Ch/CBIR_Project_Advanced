# 06 — Graphs & Visualizations

## Overview

All visualizations are generated by `generate_graphs.py` and saved in the `graphs/` folder. Both PNG (for viewing) and PDF (300 DPI, for research papers) versions are created.

---

## How to Generate

```powershell
.\cbir_env\Scripts\Activate.ps1
python src/generate_graphs.py
```

**Prerequisite:** Run `python src/batch_evaluate.py` first so that `features/evaluation_results.pkl` exists with real data. Otherwise, default/estimated values are used.

---

## Graph 1 — Scalability Line Graph

**File:** `graphs/scalability_graph.png`

- X-axis: Dataset Size (number of images)
- Y-axis: mAP (%)
- Shows how retrieval accuracy changes with increasing dataset size
- Area under curve filled for visual impact
- Data labels show exact mAP + dataset name

---

## Graph 2 — Precision Bar Chart

**File:** `graphs/precision_comparison.png`

- Side-by-side bar chart comparing all 4 datasets
- Sorted by dataset size (smallest to largest)
- Each bar shows mAP value, image count, and category count
- 80% baseline reference line included

---

## Graph 3 — Latency-Accuracy Trade-off

**File:** `graphs/latency_accuracy.png`

- Bubble chart: X = latency (ms), Y = mAP (%)
- Bubble size proportional to dataset size
- Shows the speed vs quality trade-off
- Useful for deployment decision-making

---

## Graph 4 — Combined Metrics Summary

**File:** `graphs/combined_metrics.png`

- Two side-by-side charts:
  - **Left:** Dataset composition (images vs categories)
  - **Right:** Horizontal bar chart showing mAP ranking
- Provides a complete overview in one figure

## New: Model Comparison Graphs (ViT-B/16 vs ResNet50)

The following additional visualizations are generated by `compare_benchmarks.py` and saved in `graphs/`:

### 1. Grouped Bar Chart — Accuracy Comparison
**File:** `graphs/comparison_accuracy.png`
- Shows mAP (%) for both ResNet50 and ViT-B/16 on each dataset
- Winner indicators highlight the best model per dataset

### 2. Grouped Bar Chart — Latency Comparison
**File:** `graphs/comparison_latency.png`
- Shows retrieval latency (ms) for both models
- Speedup annotations show how much faster ViT is

### 3. Scatter Plot — Accuracy vs Speed Trade-off
**File:** `graphs/vit_vs_resnet_accuracy_speed.png`
- Each point: (latency, mAP) for a model-dataset pair
- Arrows connect ResNet50 and ViT for the same dataset
- Ideal region (high accuracy, low latency) is highlighted

### 4. Dashboard — Combined Metrics
**File:** `graphs/comparison_dashboard.png`
- Multi-panel summary: accuracy, latency, speedup, averages
- Visualizes overall model performance and trade-offs

### 5. Radar Chart — Multi-Metric Comparison
**File:** `graphs/radar_comparison.png`
- Compares datasets across normalized metrics (accuracy, size, speed, categories)
